❓ מה הבעיה בקוד הבא?

useEffect(() => {
  setInterval(() => {
    setSeconds(seconds + 1);
  }, 1000);
}, []);
▼ השתמש בחצים למעלה/למטה כדי לנווט

❌ בעיה #1 – אין ניקוי (Cleanup)

  • 🏃‍♂️ ה־Interval ממשיך לרוץ לנצח
  • 👻 קורה גם כשהקומפוננטה יוצאת מהמסך (Unmount)
  • 💥 גורם לזליגת זיכרון (Memory Leak) ובאגים

❌ בעיה #2 – תלויות שגויות (Stale Closure)

setSeconds(seconds + 1);

// ... בהמשך הקוד
}, []); // התלות ריקה!
  • useEffect רץ פעם אחת בלבד (בגלל הסוגריים הריקים)
  • המשתנה seconds "נתקע" על הערך ההתחלתי
  • הקוד תמיד יציג: 0 + 1 = 1

✅ הפתרון הנכון

useEffect(() => {
  const id = setInterval(() => {
    // שימוש ב-Callback כדי לקבל ערך עדכני
    setSeconds(prev => prev + 1);
  }, 1000);

  // פונקציית הניקוי רצה ב-Unmount
  return () => clearInterval(id);
}, []);

🎯 המסר לבית

  • ⚠️ קוד ש"רץ" הוא לא תמיד קוד נכון
  • 🧹 כל תהליך מתמשך (Event, Interval) חייב Cleanup
  • 🔄 שינוי State בתוך אפקט? השתמשו ב-Updater Function (prev)
